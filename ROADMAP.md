## 9. Финальная проверка перед запуском

Финальная проверка отложена по решению пользователя после завершения текущих интеграционных изменений.

- Пройти полный цикл: регистрация → заявка → приём → назначение → Telegram → оплата → старт → завершение → отчёт.
- Проверить мобильную версию, ошибки API, отказоустойчивость и восстановление из резервной копии.
- Выполнить security review и закрыть все критические дефекты.
- Только после этого публиковать production-версию.
